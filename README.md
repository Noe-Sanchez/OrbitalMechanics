# OrbitalMechanics
ROS2 rviz simulation of a satellite making a 3D orbit around earth, including orbital elements calculation, RK4 physics integration and the 6 directions of thrust along the normal, prograde and radial vectors. Additionally, orbital element based control is implemented.
